# Davetech — Multi-tenant business platform

Cloud software for small and medium businesses in Kenya. One platform, many
business types, each customer on their own subdomain.

**Live:** https://davetech.co.ke  ·  Try a demo with one click on the home page.

## Business types
- Shop and retail: till, stock, suppliers, reports
- Pharmacy: batches, expiry tracking, controlled stock
- School: fees, receipts, results, ID cards
- Bookshop: ISBN, school book orders, consignment
- Hotel and bar: rooms, tables, orders, bills
- Salon and barber: service price list, till, stylist commission
- Chama: savings, loans, turns

## Highlights
- Multi-tenant: separate data and subdomain per customer
- Roles and permissions (owner, manager, cashier, teacher)
- M-Pesa and cash payments, printable A4 and thermal receipts
- Server-side business logic in Cloud Functions; the database blocks direct client writes
- Platform admin console: create customers, switch modules, edit the website

## Tech stack
React, TypeScript, Vite, Firebase (Authentication, Firestore, Cloud Functions,
Storage), Cloudflare, Render
